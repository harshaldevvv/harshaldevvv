# Hi, I'm Harshal

I build **[BallEngine](https://ballengine.app)**, a physics simulator that turns satisfying ball simulations into short videos creators use to grow and monetize their channels.

I work across the whole stack: a real-time physics and rendering engine in TypeScript, GPU video rendering, Cloudflare Workers backends and billing. Before that I made games in Unity and C#.
